# Document Corpus

The files in this directory are sample documents used to test document ingestion and retrieval locally.

To replace the corpus:

1. Remove the sample files.
2. Add approved business documents in PDF, DOCX, or HTML format.
3. Start the API and Streamlit app.
4. Upload the files through the sidebar so the app records document metadata and indexes chunks in Chroma.

Do not commit private customer records, contracts with sensitive personal data, local vector stores, or generated database files.
